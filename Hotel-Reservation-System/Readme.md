# 🏨 Hotel Reservation System

A simple **Hotel Reservation System** developed in **Java** using **Object-Oriented Programming (OOP)** and **File Handling**. This project allows users to search available rooms, book rooms, cancel reservations, and view reservation details through a console-based interface.

---

## 📌 Features

- View available rooms
- Search rooms by type
- Book a room
- Cancel a reservation
- View all reservations
- Payment simulation (Cash / Card / UPI)
- Store reservation details using File Handling (`bookings.txt`)

## 🚀 How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/Hotel-Reservation-System.git
```

2. Open the project in **VS Code**.

3. Navigate to the `src` folder.

4. Compile the project:

```bash
javac *.java
```

5. Run the project:

```bash
java Main
```
